## New Project Workflow

1. **[Project Plan](docs/project-plan.md)** — Fill out the PRD: what you're building, for whom, business model
2. **[Implementation Plan](docs/implementation-plan-template.md)** — Copy the template, fill in intent, constraints, phases. This is what Claude executes against.
3. **GitHub Issues** — Run `set up GitHub Issues for [project-name]` to generate issues from your phases
